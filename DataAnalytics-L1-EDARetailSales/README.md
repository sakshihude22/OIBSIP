# Retail Sales Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA)
on retail sales data using Python.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data Inspection
- Missing Values and Duplicate Analysis
- Statistical Analysis
- Monthly and Quarterly Sales Trends
- Gender Analysis
- Age Group Analysis
- Product Category Analysis
- Top 10 Revenue Transactions
- Correlation Heatmap
- Sales Distribution

## Key Findings
- Electronics generated the highest revenue.
- Female customers generated higher sales.
- Customers aged 36-50 generated the highest revenue.
- May 2023 recorded the highest monthly sales.

## Conclusion
The project identifies useful retail sales trends
and provides business recommendations.
